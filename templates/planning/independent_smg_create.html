Новый СМГ

Для одного объекта и месяца можно создать несколько независимых вариантов с разными названиями. Утверждённый действующий вариант будет один: новый нельзя утвердить, пока прежний не отменён явно. Выберите объект и месяц. Затем добавьте работы и ресурсы, заполните дни и настройте их связи.

Как начать

ГПР можно выбрать сейчас или связать позже. Без копирования СМГ создаётся пустым.

Из ГПР самого объекта можно скопировать месячный план. Из общего ГПР родителя добавляется только состав работ с нулевыми объёмами: каждый субобъект планирует свой вклад.

Техника добавляется по плановым позициям, как в ГПР. Численность и количество общие для всех выбранных работ; ГСМ относится к объекту.
