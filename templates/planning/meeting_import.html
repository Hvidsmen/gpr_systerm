Импорт плана из файла совещания

Каждый выбранный лист — отдельный строительный объект. Загрузка создаёт новый черновик плана на выбранный период; существующие планы сохраняются.

Читаются только дневные столбцы с датами внутри выбранного периода. Месячные итоги из шапки не используются.

Загружаются только плановые работы, люди и техника. Факт, накопительное выполнение и сведения о наличии техники не загружаются. Строительные объекты берутся только из выбранного проекта в базе: название листа должно совпадать с названием объекта. Недостающие разделы и справочные позиции создаются после подтверждения. Новые работы создаются простыми с равномерным профилем. Существующие подработы сопоставляются по названию, единице и разделу; основная составная работа рассчитывается по нормативам всех подработ.
