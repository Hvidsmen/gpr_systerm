Загрузка бригад из Excel

Загрузите файл .xlsx до 5 МБ и 5000 строк. Первая строка — заголовки: Название, Группа, Макрогруппа, Описание, Активна, Единица измерения.

Обязательно только название. Новые группы и макрогруппы создаются в справочниках. Единица измерения по умолчанию — «чел.», активность — «Да». Для отключения укажите «Нет».

Существующие названия и повторы пропускаются без изменения данных. Если есть ошибки, весь импорт отменяется.
