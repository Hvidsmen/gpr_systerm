Загрузка техники из Excel

Загрузите файл .xlsx до 5 МБ и 5000 строк. Первая строка — заголовки: Название, Группа техники, Единица измерения, Активна.

Обязательно только название. Новые группы техники создаются автоматически. По умолчанию единица измерения — ед., активность — «Да». Для отключения укажите «Нет».

Существующие названия и повторы пропускаются без изменения данных. Если есть ошибки, весь импорт отменяется.
