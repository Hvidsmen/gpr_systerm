Обновить группы техники из Excel

Файл из справочника техники

Подходит ваша выгрузка со столбцами «Название», «Техника для планирования», «Группа техники». VIN и госномера для неё не нужны.

Группа обновляется у существующей техники для планирования, всех её моделей и связанных машин. Модель находится по названию. Если плановая позиция в файле устарела, используется текущая связь из справочника; расхождение показывается в предпросмотре. Переноса модели между плановыми позициями нет. Единицы измерения, активность и категории водителя не меняются.

Регистр и повторные пробелы в названиях групп не мешают сопоставлению. Пустая группа сохраняет текущую; «Без группы» очищает назначение. Если у одной плановой позиции указаны разные группы, обновление отменяется. Новые группы создаются только после подтверждения. Техника, модели и машины не создаются. Неизвестные записи перечисляются в предупреждениях.

Если файл содержит конкретные машины с номерами

Сохраняется прежняя загрузка по ID, VIN, инвентарному номеру или госномеру. Она меняет технику для планирования только у указанных машин; группа наследуется от выбранной плановой позиции. Колонка «Группа техники» проверяет совпадение. Такой файл применяется при загрузке.
