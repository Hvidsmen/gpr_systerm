Обновить группы существующих машин из Excel

Скачать текущие машины в Excel

Используйте экспорт машин. Меняется «Техника для планирования», группа наследуется автоматически. Машины, модели, плановые позиции и группы не создаются.

Поиск машины — по ID, VIN, инвентарному номеру или госномеру. Все указанные идентификаторы должны соответствовать одной машине. Неизвестные и неоднозначные значения пропускаются с предупреждением. Меняются только указанные машины. Для машины с моделью должна существовать соответствующая модель нового корня; иначе строка пропускается. Группа наследуется от техники для планирования. Колонка «Группа техники» служит проверкой: при несовпадении строка пропускается. Для смены группы у всех моделей и машин измените её в карточке плановой позиции. Пустые значения сохраняют текущее назначение. Остальные колонки игнорируются.
