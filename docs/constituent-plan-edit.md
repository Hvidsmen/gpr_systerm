# Редактирование работ в составе комплекса в месячном ГПР

В редакторе месячных распределений под комплексом доступны поля «План на месяц» для каждой работы в составе. Отдельные объёмы сохраняются в item_quantities и используются при построении дневного плана. Объём комплекса рассчитывается по минимальному отношению объёма работы к её нормативу (с учетом дробности комплекса).

Изменение общего объёма комплекса сбрасывает отдельные объёмы и возвращает расчёт по нормативам. Изменение профиля сохраняет отдельные объёмы. Старые импорты и сохранение без JavaScript сохраняют прежнее поведение. При изменении отдельных объёмов прежняя точная дневная раскладка сбрасывается и строится заново по профилю. Нули допустимы; неполный состав, отрицательные, нечисловые и чужие работы отклоняются сервером. Изменение разрешено только в редактируемых версиях существующим механизмом доступа.
