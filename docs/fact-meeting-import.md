# Импорт факта из файла совещания

Открыть «Факт объекта за день» или «Журнал фактов» → «Импорт факта из Excel».

1. Выбрать существующий строительный объект, начало и конец периода.
2. Загрузить `.xlsx` и выбрать поведение для существующих фактов: сохранить (по умолчанию) или заменить.
3. Прочитать файл, проверить предварительный просмотр и подтвердить импорт.

Читается только лист, название которого совпадает с названием выбранного объекта (регистр, крайние пробелы несущественны). Даты берутся из дневных заголовков без исправления года по названию месяца. Загружаются явно обозначенные строки «факт» работ, людей и техники, с восстановлением названий и единиц из предыдущей строки плана. Неразмеченные строки, плановые и сводные показатели не считаются фактом. ГСМ в этом шаблоне не распознаются.

Каждая заполненная ячейка сохраняется на свою дату; количество людей и техники не усредняется. Пустые ячейки пропускаются, нули сохраняются. Объёмы работ округляются до трёх знаков. Конечная точка в единице измерения удаляется.

Работы и подработы сопоставляются внутри объекта по названию, единице и разделу; ресурсы — по названию и группе/категории. Неоднозначные совпадения и повторные позиции в один день блокируют импорт. Недостающие позиции показаны как «Создать» и создаются только после подтверждения. Объекты не создаются. Для составной работы импортируются факты подработ, допускается частичное заполнение; итог основной работы рассчитывается системой накопительно по нормативам.

Замена меняет только фактическое количество, сохраняя комментарии и прочие поля; автор факта работы становится пользователем импорта. Планы не меняются. Вся запись выполняется в одной транзакции. Если данные изменились после просмотра, требуется повторная загрузка. Подтверждение одноразовое, срок — один час.

Доступ: администратор и мастер. Мастер выбирает только закреплённые за ним объекты; права повторно проверяются при подтверждении.
