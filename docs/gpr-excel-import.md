# Дополнительный импорт месячного ГПР из Excel

Откройте «Планирование» → «Импорт ГПР из Excel (XLS / XLSX)».

1. Выберите строительный объект вручную. Название листа не должно совпадать с объектом.
2. Загрузите один файл XLS или XLSX. Если в книге несколько ГПР, автоматически выбирается лист «ГПР», иначе первый распознанный лист. Другой лист можно указать явно. Варианты одного плана не складываются друг с другом; служебные листы не импортируются.
3. Укажите плановый год — год января. Месяцы до января относятся к предыдущему году. Пустое поле сохраняет даты Excel.
4. Проверьте даты каждого столбца в предварительном просмотре. Их можно исправить независимо, включая ошибочные или повторяющиеся заголовки. Все даты должны быть первым числом месяца и не повторяться.
5. Проверьте объёмы и действия со справочниками. После подтверждения создаётся новый черновой ГПР; существующие планы и факт не перезаписываются. Повторное подтверждение того же просмотра не создаёт ещё один ГПР.

Поддержаны предоставленные варианты Таналау, мостовых переходов Пайяха/Чирвияха и ресурсного ГПР Сузун: прямые месячные даты, объединённые заголовки годов и названия месяцев, смещённые столбцы, работы и итоговые блоки людей/техники.

Ресурсы берутся из последнего итогового блока. Повторные потребности под отдельными работами не добавляются к общему итогу. Люди и техника — месячная численность, без выдуманных часов и ставок. ГСМ при наличии явно обозначенного блока загружается как расход; остаток из расхода не вычисляется.

Пустые и нулевые месячные позиции пропускаются. Работы без числовых месячных объёмов показываются предупреждением: цветные полосы, суточный темп и даты начала/окончания не превращаются автоматически в месячные объёмы. Формулы читаются по значениям, сохранённым Excel. При отсутствующих результатах откройте файл в Excel, пересчитайте и сохраните.

Дробные объёмы работ округляются до 0,001, расход ГСМ — до 0,01 с предупреждением. Дробная численность людей/техники не принимается. Разделы, работы, группы ресурсов и позиции создаются только после подтверждения. Позиции сопоставляются с учётом раздела или группы; группы файла сохраняются. Однозначно найденные существующие позиции используются повторно; при дублях ресурсов показывается выбранный ID. Существующие составные работы допускают месячный объём основной работы.

Для XLS требуется `xlrd` из `requirements.txt`. Ограничения: 8 МБ файла, 64 МБ распакованного XLSX, 2500 строк выбранного листа и 10000 ненулевых месячных записей.

## Импорт в открытую версию

В месячном редакторе, блок «Excel: импорт, экспорт и шаблон» → «Импорт файла ГПР в эту версию». XLS/XLSX проходят существующее распознавание и подписанный предварительный просмотр с редактированием месяцев. Объект закреплен за версией; заголовок нового плана не запрашивается. Импорт разрешен только DRAFT/REJECTED и только в доступные для редактирования месяцы периода. Столбцы за пределами периода вызывают ошибку без сохранения.

Совпадающие работы/ресурсы в месяцах файла обновляются, отсутствующие в файле строки сохраняются. Утвержденные планы и факт не изменяются. Все изменения выполняются атомарно, повтор подтверждения не дублирует импорт. Токен привязан к целевой версии, пользователю и компании. Обычный импорт с созданием нового ГПР остается доступен.

Лист «ГПР_23км без МОП» (ресурсный Сузун): единица определяется по явному заголовку «Ед. изм.», а не по смещению относительно названия. Общая нумерованная работа с последующими ненумерованными строками той же единицы служит разделом, объемы берутся из детальных строк без двойного учета. Текстовые пометки в месячных ячейках работ (например «проезд») пропускаются с предупреждением. Некорректные числа, отрицательные объемы и ошибки ресурсных количеств по-прежнему отклоняются. Для книги с несколькими альтернативными ГПР указывайте нужный лист явно.

Поле ручной замены годов по умолчанию пустое — в том числе при импорте в существующую версию. Год начала версии не подставляется: в сезонном плане ноябрь 2026 перед январем 2027 должен оставаться ноябрем 2026. Замена годов выполняется только при явном заполнении поля пользователем.
