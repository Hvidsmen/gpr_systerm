# Добавление веток справочника в ГПР и СМГ

В месячном редакторе ГПР / рабочих пространств СМГ есть блок «Добавить из справочника: объект → комплекс → работа». Выберите одну позицию и нужные месяцы. В дневном СМГ тот же выбор находится в форме добавления строки раздела «Работы».

- Комплексный объект добавляет все доступные комплексы работ этого объекта с их составом.
- Комплексная работа добавляет только себя и вложенные работы; принадлежность комплексному объекту сохраняется.
- Работа в составе комплекса добавляет только эту ветку (в том числе её потомков), с родительским комплексом и комплексным объектом. Смежные комплексы и работы не добавляются.
- Самостоятельные работы можно добавлять отдельно, без искусственного комплексного объекта.

В месячных строках `WorkMonthAllocation.selected_item_ids` хранит выбранный состав: пустой список сохраняет прежнее поведение «весь комплекс», непустой — явный список ID работ своего комплекса. Состав проверяется на сервере и сохраняется в скрытом поле редактора. Месяцы могут иметь разный состав. Пересчёт, редактор и Excel сохраняют этот выбор; снимок периода содержит объединение выбранных работ месяцев, дневные строки каждого месяца — только его состав.

Добавление повторной позиции не обнуляет данные. При расширении частичной ветки сохраняются введённые объёмы и дневное распределение, новые вложенные работы получают нулевые объёмы. В дневном СМГ сохраняются существующие значения по дате и ID работы, а новая редакция переносит состав применённого СМГ.

Снимок частичного комплекса содержит видимые `items` и полный нормативный состав `valuation_items`. Это позволяет отображать только выбранную ветку, но не считать выполнение одного элемента выполнением всего комплекса для реальной стоимости. Оценочная стоимость продолжает учитывать веса фактически запланированных работ. Автоматические остатки частичного комплекса распределяются по объёмам выбранных работ, а не по нулевому объёму всего незавершённого комплекса.

Изменение состава доступно планировщику / администратору только в черновике или отклонённой версии, дневной СМГ — только в черновике. Проверяются компания, назначение строительного объекта, доступный справочник, принадлежность работ и месяцы. Изменение состава входит в подписи проверки сметчиком и подготовки ресурсов. Пустой новый список не меняет прежние подписи, поэтому обновление само по себе не аннулирует проверки старых планов.

Для новых пользователей месячный редактор группируется «Комплексный объект → Комплекс → Работа»; ранее сохранённая настройка группировки сохраняется. Можно выбрать новую группировку вручную.

Проверки выпуска: 43 целевых теста выбора веток, месячного редактора / Excel, дневного СМГ, новой редакции, стоимости и подготовки плана прошли. JavaScript проверен на синтаксис, миграции согласованы с моделями. Расширенный прогон до завершающих трёх тестов: 130 проверок, 108 прошли, 22 прежних сбоя воспроизведены без изменений задачи в отдельной копии опубликованного main (права устаревших тестовых сценариев, назначения объектов). Новых сбоев в этом прогоне нет.
