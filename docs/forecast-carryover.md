# Прогноз и уточнение остатка

При подготовке следующего месяца до закрытия предыдущего кнопка добавления остатка рассчитывает прогноз. Учитывается факт с начала предыдущего месяца по вчера включительно. Прогноз выполнения = факт / прошедшие календарные дни × календарные дни месяца. Прогноз остатка = максимум(план − прогноз выполнения, 0). Отсутствующий факт считается нулем. Для составной работы расчет выполняется по каждой подработе. Если прошедших дней нет, выполнение принимается нулевым.

Прогноз подписан в предварительном просмотре и в примечании работы. Отсутствующие работы добавляются; существующие месячные объемы сохраняются, остаток отмечается отдельно. Даже нулевой прогноз регистрируется, чтобы его можно было сверить с закрытым фактом.

При переносе прогноза создается задание планировщику на первое число планируемого месяца. Задания появляются в меню «Задания по остаткам» с индикатором; фонового сервера и внешних сообщений не требуется. До срока задания можно увидеть в списке предстоящих. Ответственный — выполняющий перенос планировщик; для администратора выбирается первый действующий планировщик компании, а при его отсутствии — сам администратор.

С первого числа задание показывает прогноз и фактический остаток прошлого месяца. Сохранение корректировки обновляет только автоматически добавленные остатки, которые не изменили вручную; для остальных обновляется примечание, а ручной объем сохраняется. Утвержденный план не редактируется: создается отдельная версия. Задание закрывается после утверждения корректировки. Допсогласование идет по общему маршруту с проверкой сметчика. Перед подтверждением необходимо проверить полноту журнала факта.
