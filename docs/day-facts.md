# Факт объекта за день

Откройте **Производство → Факт объекта за день**, выберите обязательный
строительный объект и дату и нажмите **Открыть день**.

На одном экране доступны работы и подработы, люди, техника и ГСМ.
Для работ показаны единицы измерения, для подработ — нормативы.
Для ресурсов из плана показаны дневные плановые количества и часы.

- Существующие факты выбранного дня загружаются для редактирования.
- Простые работы вводятся непосредственно, составные — по подработам.
  Объём вводится за день, а накопительное выполнение рассчитывается автоматически.
- Ресурсы из последней утверждённой версии периода подставляются вместе со
  ставками. Если такой версии нет, используются прежние дневные планы объекта.
  Плановые количества не копируются в фактические автоматически.
- Дополнительные ресурсы можно добавить кнопкой **Добавить строку**.
- Пустые незаполненные строки не создают фактов. Явно введённый ноль сохраняется.
  Если строку начали заполнять, фактическое количество обязательно.
- Людские часы — суммарные человеко-часы, часы техники — суммарные машино-часы.
- Для удаления существующей записи отметьте **Удалить**.

Кнопка **Сохранить факт за день** сохраняет изменения всех четырёх разделов
в одной транзакции. При ошибке ни одна категория не сохраняется, введённые
значения остаются на экране. Повторное сохранение редактирует загруженные
записи; дубли ресурса или работы/подработы за ту же дату отклоняются.
Строки работ не отображают отдельные смены: их объёмы нужно объединить за день.

Ввод, исправление и удаление доступны администратору и мастеру. Мастер видит
только назначенные строительные объекты. Руководитель и планировщик могут
просматривать факт без изменения. Данные ограничены компанией и выбранным объектом.
Исправления фактов участвуют в следующих уточнениях плана; зафиксированные
снимки утверждённых версий не изменяются.

Старые отдельные формы ввода остаются доступны. Импорт Excel, согласование
фактов и закрытие периода этим изменением не добавляются. Изменение базы
данных и новые миграции не требуются.

## Журнал фактов в виде матрицы

В журнале даты расположены по столбцам, работы и подработы — по строкам.
По умолчанию открыт текущий месяц. Можно выбрать строительный объект,
работу и период до 366 дней. Итог строки — сумма записей за выбранный период
в единице этой работы или подработы. Для составных работ в журнале показываются
исходные объёмы подработ; итог основной работы рассчитывается по нормативам
в отчётах. Ноль означает введённый нулевой факт, «—» — отсутствие записи.

Корзина в ячейке открывает подтверждение удаления конкретной записи с объектом,
работой, подработой, датой и объёмом. Удаление выполняется только после нажатия
«Удалить факт» на странице подтверждения. После удаления сохраняются фильтры
и период журнала, а текущие итоги факта пересчитываются.

Удалять записи могут администратор и мастер. Мастер видит и удаляет только факты
своих назначенных строительных объектов. Для остальных ролей журнал доступен
по правилам чтения без кнопок удаления. После создания или редактирования факта
журнал открывается на месяце этой записи, в том числе для прошлых периодов.
