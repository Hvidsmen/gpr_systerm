# Переход портала на Microsoft SQL Server

Целевая конфигурация: сервер `MSK-DB2`, база `YDS_PORTAL`, встроенная Windows-аутентификация от `YAMALGAZPROM\dvivanov`.

Переход выполняется поэтапно. Добавление поддержки MSSQL не переключает рабочую SQLite-базу и не изменяет её данные.

## 1. Подготовка SQL Server

На сервере должен быть установлен SQL Server 2017 или новее. На компьютере портала нужен **Microsoft ODBC Driver 17 for SQL Server** — именно он подтверждён проверкой рабочего сервера. Отдельная диагностическая команда умеет также проверить Driver 18.

Администратор SQL Server создаёт пустую базу и выдаёт учётной записи портала права на схему и миграции:

```sql
CREATE DATABASE [YDS_PORTAL];
GO
CREATE LOGIN [YAMALGAZPROM\dvivanov] FROM WINDOWS;
GO
USE [YDS_PORTAL];
CREATE USER [YAMALGAZPROM\dvivanov] FOR LOGIN [YAMALGAZPROM\dvivanov];
ALTER ROLE [db_owner] ADD MEMBER [YAMALGAZPROM\dvivanov];
GO
```

Если логин или пользователь уже существует, соответствующую команду пропускают. Удалять либо очищать существующую базу этим скриптом нельзя.

## 2. Проверка доступа

После обычного обновления портала запустите `CHECK_GPR_MSSQL.cmd` именно от `YAMALGAZPROM\dvivanov`. Скрипт только подключается, читает сведения о сервере и показывает фактическую Windows-учётную запись. Рабочая база остаётся SQLite.

Ожидаемый результат начинается с `ГОТОВО` и содержит сервер `MSK-DB2`, базу `YDS_PORTAL` и вход `YAMALGAZPROM\dvivanov`.

## 3. Перенос и переключение

Сначала запустите `PREPARE_GPR_MSSQL_COPY.cmd` от `YAMALGAZPROM\dvivanov`. Он принимает только полностью пустую `YDS_PORTAL`, создаёт согласованный снимок SQLite, схему MSSQL, переносит данные и сверяет первичные ключи всех моделей. Рабочий портал на этом шаге продолжает использовать SQLite. Снимок и `verification.json` сохраняются в `.runtime\mssql-copy`.

Окончательное переключение выполняется отдельно, после успешной сверки: с остановкой портала, финальным снимком и проверкой запуска. До этого не добавляйте `DJANGO_DB_ENGINE=mssql` в рабочий `.env`.

Тестовый и учебный порталы пока продолжают использовать отдельные SQLite-копии. Это исключает подключение теста к рабочей базе MSSQL.
