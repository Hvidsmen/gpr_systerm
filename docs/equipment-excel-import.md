# Импорт видов техники из Excel

В справочнике «Виды техники» нажмите «Загрузить из Excel» и скачайте шаблон.
Заполните первый лист и загрузите файл `.xlsx`.

| Столбец | Правило |
| --- | --- |
| Название | Обязательно, до 150 символов |
| Категория | Необязательно; отсутствующая категория создаётся в компании пользователя |
| Единица измерения | Необязательно, по умолчанию `ед.`, до 50 символов |
| Активна | `Да` или `Нет`; пустое значение означает `Да` |

Существующие названия и повторы внутри файла пропускаются без обновления.
Сравнение названий и категорий не учитывает регистр. Импорт доступен
администратору и планировщику. Данные относятся только к их компании.

Файл ограничен 5 МБ и 5000 строками. Заголовки находятся в первой строке;
формулы нужно заменить обычными значениями. Ошибка в любой строке отменяет
весь импорт. На странице отображаются номера строк с ошибками или итоги:
добавленные виды техники, пропущенные повторы и новые категории.

При обновлении установите зависимости: `python -m pip install -r requirements.txt`.
