# Назначение сотрудника на должность СМГ / ГПР

В разделе **Персонал → Ведение персонала**, в заголовке должности с планом, нажмите **Назначить сотрудника**. Должность, объект, выбранный ВЖГ и дата отчёта подставляются в форму. Если в заголовке есть СМГ подобъекта и родительский ГПР, по умолчанию выбирается конкретный объект СМГ.

Выберите действующего сотрудника из справочника. Поиск работает по имени, штатной должности и табельному номеру. Проверьте объект и ВЖГ, укажите начало и при необходимости конец назначения. Можно выбрать существующий график или оставить «Пока без графика».

Назначение — отдельная связь с должностью плана: штатная должность в ЗУП/кадровом справочнике не переписывается. Одна запись используется в сравнении с СМГ и ГПР. ГПР родительского объекта учитывает назначение на дочерний объект; назначение на соседний объект не закрывает потребность только из-за общего ВЖГ.

При первом вводе можно заполнить блок **Начальное состояние**:

- **На вахте** — обязательна реальная дата заезда.
- **МО** — обязательна дата выезда на отдых. Если известна дата предыдущего заезда, укажите её; иначе оставьте пустой, вымышленный заезд не создаётся.
- **Не указывать** — сохраняется только назначение, без изменения фактического статуса.

Для первичного учёта допускаются даты в прошлом, в том числе за пределами обычного окна ежедневного ввода. Будущие даты и даты позже начала назначения не принимаются. Статус и назначение сохраняются одной транзакцией с автором в истории; дни вахты / МО и прогноз графика считаются от введённых дат. Повторная отправка не создаёт дубликатов.

Блок доступен, пока у сотрудника нет истории перемещений, включая ранее созданное пустое назначение через «Назначение». Если история уже есть, начальные поля отключены или не показываются. Существующие заезды и выезды не переписываются этой формой. Дальнейшие перемещения оформляются через **Заезд / выезд**, исправления — через историю с действующими правилами доступа. Проживание коменданта не меняется.

Без начального статуса или фактического заезда сотрудник виден в списке назначенных, но не увеличивает «На вахте» и не закрывает дефицит присутствия. Если человек фактически в другом ВЖГ, список показывает это отдельно.

Ссылка **Назначение** в строке сотрудника открывает изменение должности плана, объекта, ВЖГ, периода и графика. Сам сотрудник при изменении фиксирован. Чтобы назначить его на другой период, сначала завершите прежнее назначение: пересекающиеся периоды запрещены. Даты окончания включительны. Повторная отправка того же назначения не создаёт вторую запись.

Доступ: администратор, руководитель кадровой службы и диспетчер по персоналу, только в своей компании. Изменения применяются к назначениям и графикам, фактических записей заезда/выезда они не создают.
