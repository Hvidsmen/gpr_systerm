# Копирование цены между работами

При создании работы или в карточке работы → «Изменить цену» доступно поле «Взять цену из другой работы» с поиском по названию, проекту, объекту и разделу.

Кнопка «Найти одинаковые работы» ищет точные совпадения названия и единицы измерения в своей компании, независимо от раздела. Регистр, лишние пробелы и е/ё не влияют на совпадение. Единственный источник выбирается автоматически; при нескольких совпадениях пользователь выбирает вариант. «Все работы» возвращает полный список для ручного выбора. Архивные исходные работы после объединения исключены.

При сохранении цена вычисляется на сервере: для создания — на текущую дату, для изменения — на дату начала действия, для исправления — на дату исправляемой записи. Единицы измерения проверяются и при ручном выборе. Источник отмечается в истории цены. Копирование выполняется один раз: последующее изменение цены источника не меняет цену получателя. Цены зафиксированных планов сохраняются.

Выбор источника и сохранение работают и без JavaScript; автопоиск и предварительное отображение цены требуют JavaScript. Чтобы ввести цену самостоятельно, выберите «Ввести цену вручную».

Проверка: `python manage.py test apps.works.test_price_inheritance apps.analytics.test_revenue`.
