# Архив пользователей

В «Пользователи и доступ» отметьте строки либо включите «Все найденные по фильтру, на всех страницах». Нажмите «В архив», проверьте список и подтвердите действие. Свою учётную запись, администраторов и служебные учётные записи выбрать нельзя. За один раз обрабатывается до 5000 пользователей.

Архивные записи скрываются из обычного списка и доступны во вкладке «Архив пользователей». Вход отключается, но пароли, роли, группы, назначения на объекты и история остаются. Архивирование не удаляет данные AD. Автоматическое обновление профиля или старая форма доступа не должны включать архивную запись обратно.

Для возврата выберите записи в архиве и нажмите «Восстановить выбранных». Возвращается прежний признак активности: отключённый до архивирования пользователь останется отключённым. Чтобы назначить архивному пользователю права администратора, сначала восстановите его.

Массовое действие доступно только администратору своей компании, выполняется атомарно после подтверждения и записывается в аудит отдельно для каждой записи. Список подтверждения фиксируется подписанным токеном на 15 минут; изменение фильтра между проверкой и подтверждением не расширяет выбор.
