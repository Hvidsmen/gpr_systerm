# Подготовка ГПР и СМГ

1. Планировщик создаёт черновик и задаёт работы, их состав и объёмы.
2. В карточке плана или месячном редакторе он открывает «Подготовка плана», выбирает руководителя проекта и сметчика и передаёт работы. Одновременно создаются задание руководителю на определение ресурсов и задание сметчику на проверку цен работ. Названия, состав, нормативы и объёмы доступны сметчику только для просмотра; цены редактируются сразу в строках и сохраняются одним действием.
3. Назначенный руководитель (существующая роль `MANAGER`, «Руководитель») задаёт технику, экипажи, смены, должности и общие ресурсы объекта. Для ГПР доступны ресурсы по месяцам; для СМГ — добавление ресурсных строк и ввод по дням. Назначения ресурсов на работы доступны по ссылке «Техника, экипажи и ресурсы работ».
4. Руководитель нажимает «Ресурсы определены». Подтверждение требуется также при отсутствии потребности в ресурсах. До успешной проверки сметчика отправка на согласование недоступна.
5. После готовности обоих направлений назначенный руководитель запускает согласование. Далее сохраняются четыре профильные службы (производство, персонал, техника/ГСМ, безопасность) и утверждение генеральным директором. Согласованный СМГ применяет руководитель.

Новый маршрут применяется к ГПР и СМГ. СМГ, переданный через новый маршрут, проходит согласование даже при совпадении месячных итогов с ГПР. Ссылка на ГПР остаётся необязательной и используется для сравнения.

Планировщик не редактирует ресурсы: поля ресурсов в месячном редакторе доступны для просмотра, дневной ввод разделён по видам строк, прямые запросы к ресурсным действиям проверяются на сервере. При импорте Excel планировщиком записываются только работы; ресурсные строки проверяются по справочникам, но не записываются. Администратор сохраняет служебную возможность полного импорта и редактирования; запуск согласования всё равно требует передачи плана, подтверждения ресурсов и проверки сметчика.

Изменения ресурсов не сбрасывают новую проверку сметчика. Изменения работ, их объёмов, названий, состава или цен требуют повторной проверки. Изменения объёмов, состава работ либо ресурсов сбрасывают фактическую готовность ресурсов, пока руководитель не подтвердит их заново. Повторная передача открывает оба направления заново и позволяет переназначить ответственных. Подтверждения и передача отражаются в истории задания, отправка на согласование — в решениях раунда с реальным исполнителем.

Для проверки сметчика используется отпечаток только работ (`works-v1`), а согласование служб по-прежнему фиксирует полный план вместе с ресурсами. Проверки прежних форматов остаются читаемыми. Старые утверждённые планы, применённые СМГ и решения согласования не переписываются. Старый черновик перед новой отправкой нужно передать через «Подготовка плана».

При обновлении применяется миграция `planning.0038_plan_preparation` и `planning.0039_resource_preparation_tasks`.
