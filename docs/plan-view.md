# Просмотр версии плана

Страница `/planning/global/<id>/` показывает план по месяцам, ссылка месяца — по дням. Факт и отклонение здесь не отображаются и не запрашиваются. Самостоятельный отчёт план/факт сохраняет прежнее поведение.

Основные работы с ненулевой ценой показывают объём и сумму в рублях. Сумма рассчитывается по дневным объёмам и цене на каждую дату, затем складывается за месяц и период; при изменении цены внутри месяца применяется соответствующая история. Для отправленных и утверждённых версий используются цены из сохранённого снимка. Подработы показывают только объёмы.

При открытии черновика расчёт актуален: снимок формируется заново без сохранения. Повторная проверка каждой записи через full_clean выполняется при формировании/отправке плана, а не при чтении страницы. В базовом расчёте рабочие дни месяца переиспользуются в пределах одного расчёта; межзапросного кеша нет. Месячные распределения предварительно группируются по работе. Цены фиксируются один раз.

На небольшом тестовом базовом плане число запросов к БД в расчёте страницы снизилось с 43 до 23, включая устранение четырёх запросов к фактам. Это замер на тестовых данных, а не гарантия времени загрузки любой производственной базы.
