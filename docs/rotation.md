# Перевахта

Отдельный модуль `/rotation/`. Администратор и планировщик создают и редактируют планы; роли с доступом к чтению планирования видят матрицу. Все данные ограничены компанией.

1. Создайте перевахту, выберите версию общего плана, название и период внутри её дат.
2. Потребность по людям берётся из ресурса «Бригада», который здесь обозначается как должность. Черновики рассчитываются заново, согласованные версии используют зафиксированный снимок.
3. Установите график должности: вахта / отдых в календарных днях и опорная дата. По умолчанию 45/45.
4. «Сформировать ротацию» создаёт обезличенные места. При постоянной потребности 1 и графике 45/45 создаются два человека со смещёнными циклами. Для переменной потребности используется максимум за весь период; избыток в остальные дни виден в матрице. Повторное формирование только добавляет недостающие места, существующие личные графики не заменяются.
5. Каждому человеку можно отдельно изменить обозначение, длительность вахты/отдыха и дату начала. До этой даты он считается вне вахты. Цикл продолжается между месяцами. Поле ФИО пока не требуется.

Матрица по месяцам показывает потребность, В (на вахте) / О (вне вахты), количество на вахте, нехватку и избыток. Отсутствующая потребность обозначается прочерком, явный ноль сохраняется. Одно место на вахте закрывает одного человека в общем плане. Дорога, передача смены и сменность внутри вахты в первой версии не учитываются.

«Обновить потребность» заново читает исходную версию, сохраняя личные графики. Новые должности добавляются автоматически. При удалении должности из исходного плана ранее созданные места сохраняются, потребность по ним становится неизвестной. График должности влияет на новые места; применить его длительность к уже созданным людям можно отдельной кнопкой, которая сохраняет личные даты начала. После ручных изменений или повторного формирования проверьте нехватку: существующие персональные графики могут отличаться от схемы автоформирования.

Для запуска после обновления выполните `python manage.py migrate`. Проверки: `python manage.py test apps.rotation`.
