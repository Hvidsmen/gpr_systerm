# Формы и поиск в списках

Все страницы приложения подключают `static/core/forms.css` и `forms.js` через `base.html`. Обычные формы используют `forms/fields.html`: два столбца на компьютере, один на телефоне; комментарии и множественный выбор занимают всю строку. Скрытые поля, подписи, подсказки и ошибки Django сохраняются.

Списки получают строку поиска без внешних библиотек. Поиск учитывает все введённые слова, регистр и варианты «е/ё». Поддерживаются выбор нескольких значений, клавиатура, зависимые списки и новые строки форм. Длинные списки показываются порциями по 100 вариантов, поиск работает по всему списку.

Исходный `select` сохраняет имя, значение, родителя и события `input/change`. Без JavaScript остаётся обычный список. Для явно нативного списка задайте `data-native-select`.

Проверка: `python manage.py test core.test_form_ui`. Браузерная проверка: установите Playwright (`npm install --no-save playwright`, `npx playwright install chromium`) и запустите `node tests/forms.browser.test.cjs`. При необходимости задайте `CHROMIUM_PATH` — путь к установленному Chromium.
