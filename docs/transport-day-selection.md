# Назначение фактической техники и проверка справочника

На «Работе за день» список выбора включает свободные действующие физические машины компании, независимо от оформленного размещения. Общий пул передаётся на страницу один раз; варианты группируются при открытии выбора, без повторения всей базы в каждой строке.

Для выбранной плановой потребности группы идут так: нужный тип в текущем ВЖГ; нужный тип в других ВЖГ; нужный тип без оформленного ВЖГ; остальные машины текущего ВЖГ; остальные машины других ВЖГ; остальные без оформленного ВЖГ. Внутри сохраняется порядок справочника. Вариант показывает фактический тип, название/модель, номера, состояние и местонахождение.

`EquipmentDayRecord.planning_type` хранит закрываемую потребность, а тип физической машины остаётся в справочнике. Показатель «Назначено» относится к выбранной потребности; «На ВЖГ» — к фактическому наличию этого типа. При подстановке другого типа он явно указан в строке и экспорте.

Назначение не создаёт приезда или перевода. Для факта вне оформленного размещения `presence_required=False`; такие сохранённые строки видны в учёте выбранного ВЖГ и доступны для дальнейшего редактирования. Проверки исторического размещения прежних записей сохранены. Машина может иметь только одну дневную запись. Идентификаторы компании, доступ к ВЖГ/объекту, окно ввода, версия и общая блокировка проверяются на сервере. Резервирование для дневного факта разрешает выбор из другого ВЖГ, а операции движения сохраняют проверки реального размещения.

На вкладке работы нет общих счётчиков, импорта, создания машин, операций движения и переключателя списка. На «Состоянии и ремонте» нет кнопки приезда; у каждой машины есть перевод, выезд и списание. Массовые и индивидуальные окна содержат только выбранные машины. Кнопка ГСМ удалена из транспорта; складская страница ГСМ содержит только баланс ВЖГ и экспорт.

В транспортной форме создания физической машины нет ручного названия: оно выводится из выбранной модели, марки или планового типа. При выборе модели поле марки заполняется из справочника и блокируется; сервер также получает значение из модели, не доверяя подмене запроса. Без отдельной модели можно указать марку вручную.

Новая техника для планирования создаёт заявку `kind=equipment` со статусом PENDING и задачу ответственному EQUIPMENT_CATALOG_MANAGER. Новая физическая машина создаёт отдельную заявку `kind=machine` и отдельную задачу тому же направлению. Подтверждение и отклонение выполняются через существующую очередь; при отклонении машины новые назначения отключаются, история сохраняется. При замене предварительного планового типа существующим классификация созданных физических машин также обновляется; количества планов обрабатываются прежним механизмом замены. Автор видит свои заявки и не может принять решение за ответственного.

Миграции: `production.0030_transport_fact_planning_type`, `resources.0025_machine_catalogue_review`.
