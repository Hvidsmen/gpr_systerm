# Матрицы журналов и удаление записей

Журналы фактов работ, людей, техники и ГСМ поддерживают выбор отдельных записей
флажками и массовое удаление. Журналы планов людей, техники и ГСМ используют
такой же порядок. Месячные планы работ показаны матрицей по месяцам.

В ресурсных журналах даты идут по столбцам, объект и ресурс — по строкам.
Выберите объект и период до 366 дней. По умолчанию открыт текущий месяц.
Техника с разными номерами и ГСМ с разными привязками к технике показаны отдельно.
Ноль — существующая запись, «—» — отсутствие записи. Сумма по дням складывает
численность людей, количество техники или расход ГСМ; остатки не суммируются.
Матрица делится на страницы по 25 ресурсных строк, журнал фактов работ — по 20.

«Изменить» открывает форму конкретной записи. «Удалить» открывает подтверждение;
запись удаляется только после отправки формы. Исправлена прежняя ошибка:
удаление ресурса больше не требует заполнения полей формы редактирования.
После удаления сохраняются выбранные фильтры матрицы.

Для массового удаления отметьте нужные ячейки или нажмите «Выбрать все на странице».
«Снять выбор» очищает флажки. «Удалить выбранные» сначала показывает точный состав
записей и зависимости. «Подтвердить удаление» удаляет весь набор одной транзакцией.
Допускается от 1 до 1000 записей. Выбор привязан к пользователю, компании и виду
журнала; подтверждение действует час. При ошибке весь набор сохраняется.

Факты удаляют администратор и мастер. Мастер видит и удаляет только записи
назначенных ему объектов. Планы удаляют администратор и планировщик.
Пользователям с доступом только для просмотра кнопки удаления не показываются.

Удаление месячного плана работ удаляет его версии и дневные планы, сохраняя факты.
Если версия месячного плана служит источником сводного плана или его сохранённого
снимка, удаление блокируется с понятным сообщением. Такая же защита действует
при массовом удалении. Удаление записей журнала ресурсов не меняет снимки
утверждённых планов на период.
