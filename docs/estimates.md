# Сметы

Отдельный раздел /estimates/. Доступ на просмотр — роли чтения, импорт — ADMIN и PLANNER. Изоляция по компании.

Структура: объект смет → ЛСР → раздел (исходный заголовок) → позиция → ресурс / расчет. Строки хранят исходный номер, родительскую строку и все 12 значимых колонок формы №421. Справочники объектов, позиций, ресурсов и единиц независимы от apps.projects, apps.works, apps.resources; внешних ключей в эти приложения нет. Объединение справочников не выполняется.

Пакетная загрузка: кнопка «Загрузить сметы (несколько файлов)», выбор Ctrl/Shift, один общий объект для пакета. До 50 файлов и 100 МБ за раз. Все файлы проверяются до записи: ошибка отменяет пакет; дубликаты пропускаются. Загрузка доступна ADMIN и PLANNER; остальным показано объяснение прав.

Импорт XLSX: один распознанный лист формы №421, максимум 12 МБ / 80 МБ распакованных данных / 15 тысяч строк. Используются сохраненные значения Excel, формулы не исполняются. После загрузки показывается расшифровка. Повтор одного файла в тот же объект не создает дубликат; измененный файл — отдельный документ, автоматически версией не считается.

Суммы — из строки «ВСЕГО по смете», в рублях. Отсутствующий итог не заменяется вычисленным. Ресурсная расшифровка и ведомости заказчика входят в позиции и не суммируются второй раз. НР, СП, индексы, коэффициенты и справочные итоги сохраняются как расчетные строки.

Excel: свод, позиции, ресурсы, расчеты/итоги, отдельные листы ЛСР с уровнями группировки, собственные справочники и правила учета. Файл можно выгрузить для одной сметы либо всех смет компании.

Проверка пользовательских 18 файлов: 909 позиций, 2920 строк ресурсов, стоимость по итогам смет 67 309 308 рублей в текущих ценах. Точные денежные значения сохраняются, формат интерфейса — целые рубли. Исходные приватные файлы и свод не входят в репозиторий.

## Расчетный отчет

Иерархия отчета: работа (раздел) → подработа (нумерованная позиция) → ресурсы. Перестройка существующих загрузок происходит при открытии отчета, перезагрузка файлов не нужна.

Отчет и свод Excel вычисляют суммы подработ. Для расценок используются стоимостные составляющие ОТ, ЭМ, М (базисные суммы исходных строк составляющих), индексы и проценты НР/СП. Текущие составляющие округляются до рубля, базисные начисления — до копейки. ФОТ = ОТ + ОТм; ОТм не прибавляется к ЭМ вторично. Стоимости отдельных нумерованных материалов и оборудования берутся из их строки, а не из «Всего по позиции». Все суммы работ и сметы получаются суммированием подработ. Это расчет отчета по стоимостным составляющим, а не полное воспроизведение сметного движка из норм ресурсов и формул пояснений.

Строки «Итого», «Всего по позиции», «ВСЕГО по смете» не являются входами расчета. Последний итог служит только диагностикой отклонения. При отсутствии необходимых данных итог неизвестен (не ноль). Неизвестные итоги и расхождения явно показываются. Исходные строки остаются доступными в Excel для аудита.

Проверка 18 образцов: 16 совпадений текущей стоимости; в ЛСР12 строка транспортных расходов имеет пустые стоимости — итог неизвестен; в ЛСР17 сумма подработ 3 514 348 рублей против контрольных 3 484 845 рублей (разница 29 503 рубля). Автоматическая подгонка к итогу файла не выполняется.

Числа в интерфейсе: денежные значения — целые рубли с разделением тысяч; количества и проценты — десятичная запятая, без лишних конечных нулей, с сохранением дробной точности. Неизвестное значение — прочерк, ноль отображается как 0.

Удаление: кнопки в списке и карточке сметы, отдельная страница подтверждения, изменение только POST с CSRF. ADMIN/PLANNER, обязательная проверка компании. Удаляются документ и строки; объект и справочники остаются. После удаления тот же файл можно загрузить повторно.
