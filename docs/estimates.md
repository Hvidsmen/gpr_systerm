# Сметы

Отдельный раздел /estimates/. Доступ на просмотр — роли чтения, импорт — ADMIN и PLANNER. Изоляция по компании.

Структура: объект смет → ЛСР → раздел (исходный заголовок) → позиция → ресурс / расчет. Строки хранят исходный номер, родительскую строку и все 12 значимых колонок формы №421. Справочники объектов, позиций, ресурсов и единиц независимы от apps.projects, apps.works, apps.resources; внешних ключей в эти приложения нет. Объединение справочников не выполняется.

Импорт XLSX: один распознанный лист формы №421, максимум 12 МБ / 80 МБ распакованных данных / 15 тысяч строк. Используются сохраненные значения Excel, формулы не исполняются. После загрузки показывается расшифровка. Повтор одного файла в тот же объект не создает дубликат; измененный файл — отдельный документ, автоматически версией не считается.

Суммы — из строки «ВСЕГО по смете», в рублях. Отсутствующий итог не заменяется вычисленным. Ресурсная расшифровка и ведомости заказчика входят в позиции и не суммируются второй раз. НР, СП, индексы, коэффициенты и справочные итоги сохраняются как расчетные строки.

Excel: свод, позиции, ресурсы, расчеты/итоги, отдельные листы ЛСР с уровнями группировки, собственные справочники и правила учета. Файл можно выгрузить для одной сметы либо всех смет компании.

Проверка пользовательских 18 файлов: 909 позиций, 2920 строк ресурсов, стоимость по итогам смет 67 309 308 рублей в текущих ценах. Точные денежные значения сохраняются, формат интерфейса — целые рубли. Исходные приватные файлы и свод не входят в репозиторий.
