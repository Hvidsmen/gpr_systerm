# Исправление перепутанной структуры

Для записей, где «Работа» содержит название комплекса, а «Раздел» — название работы в его составе:

1. В справочнике «Работы» выделите нужные самостоятельные работы.
2. Нажмите «Исправить структуру». Можно выбрать одну запись или до 100 записей, включая разные объекты.
3. Проверьте таблицу преобразования. Одноимённые комплексы (без учёта регистра и внешних пробелов) объединяются в пределах одного объекта. Существующие комплексы автоматически не дополняются.
4. Выберите итоговый раздел для каждого комплекса, единицу, нормативы и профили работ. Названия составляющих заполняются из исходных разделов; их можно уточнить.
5. Выполните предварительный просмотр и подтвердите отдельной кнопкой.

Нормативы по умолчанию равны 1 и требуют проверки. Объём комплекса считается существующим алгоритмом по минимуму выполненных нормативов составляющих, а не суммированием разнородных единиц. Составляющие сохраняют исходные единицы и объёмы. Цена комплекса складывается по исходным ценам с учётом нормативов; исходные цены и работы сохраняются в истории объединения.

Используется существующая транзакционная процедура объединения: записи факта сохраняют идентификаторы, даты, авторов, комментарии и объёмы, получая ссылки на комплекс и составляющую. Черновики планов преобразуются; утверждённые снимки сохраняются и для актуальных согласованных планов создаются новые черновики на проверку/согласование. Исходные работы архивируются с явной связью происхождения. Отдельные редакции СМГ автоматически не переутверждаются: после изменения ГПР их следует проверить в обычном процессе подготовки СМГ.

Исходные разделы не переименовываются и не удаляются, поэтому другие записи в них сохраняются. Исправление доступно администратору и планировщику своей компании. Подтверждение связано с пользователем, компанией и исходными данными и действует один час; изменение работ, названий разделов, факта или планов требует нового просмотра. Повторное применение к архивным источникам запрещено.

В этой же форме можно создать раздел: оставьте выбор существующего раздела пустым и заполните «Создать новый раздел». Предварительный просмотр покажет его название; запись создаётся только при подтверждении, на объекте выбранных работ, в одной транзакции с исправлением структуры. Для нескольких комплексов одного объекта с одинаковым новым названием создаётся один раздел. При отмене просмотра или ошибке исправления лишние разделы не сохраняются. Если раздел с таким названием уже существует, выберите его из списка.
