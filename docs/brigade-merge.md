# Дубли должностей и объединение бригад

При импорте совещаний должность сопоставляется по нормализованному названию в рамках компании, независимо от группы. Для дублей справочника выбирается первая неархивная запись по ID, выводится предупреждение с выбранной записью. При повторении одной должности в одном месяце/дне одного листа берётся первая строка, остальные пропускаются с предупреждением и номерами строк; численность не суммируется при импорте повторных строк. Другие месяцы остаются отдельными. Конфликты между отдельными файлами продолжают блокироваться.

В справочнике бригад (должностей) есть «Объединить должности» и «Объединить выбранные» над таблицей. Подтверждение обязательно. Сохраняются название, единица, группа и макрогруппа выбранной активной записи. Совпадающие дневные план/факт и месячные строки черновиков суммируются по людям и часам. Несовпадающие ставки, единицы или профили отменяют всю операцию. Состав сотрудников объединяется без повторного членства одного сотрудника.

В перевахте должности одного плана объединяются, люди переносятся с сохранением личных графиков и ручных статусов. Общий график должности остаётся графиком выбранной записи. Потребность складывается. Снимки согласованных планов и исходные строки неизменны; старые ID интерпретируются через алиасы в матрицах, Excel и будущих уточнениях. Источники архивируются, связи и значения до переноса сохраняются в BrigadeMerge (просмотр в админке). Все операции ограничены компанией и доступны администратору/планировщику.
