# Дневной СМГ после утверждения месячного ГПР

В карточке утвержденной версии ГПР и в истории версий рабочего пространства — «Дневной СМГ». Выберите уточняемый месяц. Для месячного уточнения разрешен только его planning_month; для базового ГПР — любой полный месяц его периода.

Создается отдельный черновик DailySchedule с работами, подработами, людьми, техникой и ГСМ. Исходные значения и месячные итоги копируются из зафиксированного ГПР, а не из изменяемых справочников. Редактор показывает ГПР / СМГ / отклонение по дням, общая карточка — по месячным итогам; для людей и техники месячный показатель численности отображается как среднее за календарные дни. Работы — объемы, труд/техника — количество и часы, ГСМ — расход и остаток; месячный остаток ГСМ сравнивается по последнему дню.

Отклонения от месячного ГПР разрешены с предупреждением, в том числе изменение месячных сумм. Исходный ГПР не меняется. Сохранение черновика не влияет на отчеты. «Применить дневной СМГ к оперативному плану» фиксирует редакцию; изменение применяется в режиме актуального плана отчетов и при подготовке факта. Режим базового согласованного плана, явный выбор версии, карточка утвержденного ГПР и зафиксированные сводные версии сохраняют оригинальные данные ГПР. В актуальной матрице показана ссылка на примененный дневной СМГ.

После применения редактирование недоступно: новая редакция копирует последний примененный СМГ, но точкой сравнения остается исходный ГПР. Предыдущая редакция архивируется только при применении новой. Все версии сохраняются. Повторное создание возвращает уже существующий черновик. Одновременная правка одной строки защищена счетчиком revision.

ADMIN/PLANNER создают, правят и применяют, роли чтения просматривают карточки/дни. Проверки компании выполняются на сервере. Источник и статус блокируются транзакционно. Требуется миграция planning/0019_dailyschedule_dailyscheduleentry_and_more.

Для больших ГПР используются месячные SQL-проекции. Предшествующие объемы составных работ агрегируются внутри SQLite, без декодирования всех дневных строк в Python. Это сохраняет корректный расчет комплектности при переносе дней.

## Просмотр по дням

Карточка дневного СМГ оформлена таблицами как ГПР: работы сгруппированы по разделам, люди — по макрогруппе и группе, техника — по категории, ГСМ — отдельно. Название позиции показано один раз для всех ее показателей. Для каждой строки видны месячный ГПР, месячный СМГ, отклонение и значения каждого дня; при дневном отклонении ячейка подсвечивается и показывает исходный ГПР. Есть итоги ресурсов за месяц и по дням, поиск, выбор раздела, фильтр отклонений и раскрытие/сворачивание групп. Итоги раздела охватывают все его строки, независимо от поиска.

Численность людей и количество техники в месячном итоге усредняются по календарным дням; часы и расход топлива суммируются, остаток топлива берется на конец месяца. Дневные перемещения с неизменной месячной суммой также попадают в фильтр отклонений. Нажатие на название открывает существующую форму редактирования дней; права и правила применения СМГ не меняются.
