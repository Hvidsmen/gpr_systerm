# Самостоятельное планирование СМГ

В «Планировании» доступны вкладки «Планирование ГПР» и «Планирование СМГ». Во второй — список с фильтрами по объекту, месяцу, статусу, создание СМГ и переход к его дневной таблице.

СМГ принадлежит объекту и месяцу независимо от ГПР. При создании можно выбрать утвержденный ГПР для сравнения и отдельно включить копирование. Без копирования значения СМГ нулевые. Без ГПР создается пустой план, строки работ/людей/техники/ГСМ добавляются в его таблице. В черновике ГПР можно привязать, сменить или убрать: значения СМГ сохраняются, меняется сравнение; требуется повторная проверка сметчика. Сравнение без ГПР показано прочерками.

Без ГПР СМГ проходит сметчика, четыре службы параллельно и генерального директора. При наличии ГПР сохранена логика: совпадающие месячные итоги после проверки сметчика можно применить без дополнительного согласования; отклонения согласовываются. Из примененного СМГ создается новая редакция с его собственными данными, а не с копией ГПР. Связь с архивным ГПР не скрывает самостоятельный СМГ.

Один действующий СМГ на объект и месяц. Нумерация редакций также ведется по объекту и месяцу. В оперативных отчетах примененный СМГ является полным планом месяца, включая случай отсутствующего ГПР. Базовые отчеты, явно выбранные ГПР и зафиксированные сводные версии не подменяются. ГПР не изменяется при редактировании СМГ.

Миграция 0034 переносит объект из прежнего источника, сохраняет ID, строки, связи и решения. Если прежде по разным ГПР были одновременно применены несколько СМГ на один объект/месяц, действующим остается последний по дате изменения, другие сохраняются как предыдущие редакции. Редакции перенумеровываются в порядке ID. Выполнить `python manage.py migrate` перед запуском обновленной версии.
