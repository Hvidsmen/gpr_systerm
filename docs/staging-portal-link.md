# Ссылка на тестовый портал с основного

После выпуска этого изменения все администраторы увидят в основном портале «Администрирование → Тестовый портал». Ссылка открывается в новой вкладке: `http://192.168.70.9:8002/`. Вход на тестовый сервер по-прежнему разрешён только его владельцу с отдельным тестовым паролем. Видимость ссылки не выдаёт доступ к тестовой базе.

Ссылка показывается активным пользователям с правами администратора и назначенной компанией, включая суперпользователей. Логин и источник входа не ограничивают видимость. Остальные роли, просмотр от имени пользователя, учебные копии и сам тест этот пункт не видят.

Для изменения адреса задайте на основном сервере `STAGING_PORTAL_URL`. Пустой адрес скрывает пункт. После изменения настроек требуется перезапуск основного процесса в согласованное время.

Этот выпуск добавляет только навигационную ссылку, настройки её видимости и проверки. Новые таблицы, миграции, обмены и задания Windows не создаются. Выпуск кода основного портала выполняется отдельно после подтверждения; подготовленный PR сам по себе не меняет работающий сервер.
