# Ссылка на тестовый портал с основного

После выпуска этого изменения владелец увидит в основном портале «Администрирование → Тестовый портал». Ссылка открывается в новой вкладке: `http://192.168.70.9:8002/`. На тесте используется отдельный тестовый пароль; ссылка не создаёт общий вход и не меняет правила доступа тестового сервера.

По умолчанию владелец определяется по логину `admin`. Учитывается локальное имя либо логин Windows, а не отображаемое ФИО или внутренний AD GUID. Ссылка показывается только активной учётной записи с ролью администратора и компанией; при совпадении логина у нескольких активных пользователей она скрывается. Другие пользователи, просмотр от имени роли, учебные копии и сам тест этот пункт не видят.

Для изменения адреса или владельца задайте на основном сервере `STAGING_PORTAL_URL` и `STAGING_PORTAL_OWNER_LOGIN`. Пустой адрес скрывает пункт. После изменения настроек требуется перезапуск основного процесса в согласованное время.

Этот выпуск добавляет только навигационную ссылку, настройки её видимости и проверки. Новые таблицы, миграции, обмены и задания Windows не создаются. Выпуск кода основного портала выполняется отдельно после подтверждения; подготовленный PR сам по себе не меняет работающий сервер.
