# Автоматические коды

Коды проектов, объектов, разделов, работ, шаблонов, профилей, календарей,
должностей, бригад, топлива и причин отклонений назначаются при сохранении.
Ручного поля кода в формах нет; переданное клиентом значение игнорируется.
Существующие коды сохраняются при редактировании.

Примеры: `PRJ-000001`, `OBJ-000001`, `SEC-000001`, `WORK-000001`.
Счётчик отдельный для каждой компании и модели. Занятые коды пропускаются;
после удаления номер не переиспользуется. Выдача номера и создание записи
выполняются в одной транзакции. Коды из старой базы не перенумеровываются.
Импорт существующих записей может явно задавать их исторический код.

После обновления выполните `python manage.py migrate` и перезапустите сервер.
