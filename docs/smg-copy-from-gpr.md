# Копирование из ГПР в существующий СМГ

В карточке черновика СМГ кнопка «Скопировать из ГПР» переносит выбранный месяц утверждённого ГПР того же объекта: работы, вложенный состав, технику, должности и ГСМ. Копируется сохранённый утверждённый снимок; ГПР не изменяется. Планировщик может скопировать начальные ресурсы из утверждённого источника, но ручное редактирование ресурсов остаётся у назначенного руководителя. Для руководителя доступно копирование ресурсов из уже связанного ГПР.

По умолчанию заполненные и уже отредактированные строки работ сохраняются. Флажок «Заменить открытые дни заполненных работ» явно разрешает заменить открытые дни работ. Закрытые дни сохраняются точно. Уже заполненный раздел ресурсов или существующие назначения ресурсов сохраняются целиком: их данные не смешиваются с исходными назначениями повторно. Это предотвращает двойной учёт экипажей. Скопированные назначения сохраняют состав экипажа, даты и привязку к работе; при закрытых днях начинаются только в открытой части месяца. Повторный запуск не создаёт дубликатов. Результат сообщает число скопированных и сохранённых строк.

Перед копированием надо сохранить дневные изменения. Клиент блокирует отправку копирования, пока в таблице есть несохранённые значения. Сервер проверяет компанию, объект, роли, статус черновика и утверждение источника. Все изменения атомарны и аудитируются.
