# Загрузка бригад из Excel

На странице «Бригады» нажмите «Загрузить из Excel», скачайте шаблон и заполните
первый лист. Столбцы: «Название», «Группа», «Макрогруппа», «Описание», «Активна».

Обязательно только название. Коды назначаются автоматически. Новые группы и
макрогруппы создаются в компании пользователя. Пустая активность означает
«Да»; отключение — «Нет». Группа и макрогруппа выбираются независимо.

Повторы названий пропускаются без изменения существующих бригад. При ошибке
в любой строке весь импорт отменяется. Файл `.xlsx`, до 5 МБ и 5000 строк.
Импорт доступен администратору и планировщику.
