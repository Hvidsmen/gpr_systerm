# Разделы и комплексные объекты

Иерархия: строительный объект → раздел → комплексный объект → комплекс работ → работы. Комплексы и самостоятельные работы без КО находятся непосредственно в разделе.

У КО обязательная ссылка на один раздел того же строительного объекта и компании. Все его комплексы должны находиться в этом разделе. Новые КО создаются с выбором раздела; в форме работы список КО ограничен её разделом. Импорт отказывает при попытке использовать существующий КО из другого раздела. При наличии комплексов менять раздел КО отдельно от его работ нельзя.

Миграция 0015 назначает существующему КО раздел с наибольшим числом его комплексов. При равенстве выбирается раздел с меньшим ID. Остальные комплексы перемещаются туда с сохранением ID, вложенных работ и операционных записей. При конфликте служебных кодов назначается уникальный код KO-<КО>-<работа>. Для пустого КО используется первый раздел его строительного объекта; при отсутствии разделов создаётся «Комплексные объекты». Связи другой компании/строительного объекта прерывают миграцию целиком. Исторические JSON-снимки планов не переписываются.

Карточка КО открывается по названию в дереве и каталоге. Она содержит название, описание, раздел, состав и административное удаление с предварительным просмотром зависимостей.

Дерево по умолчанию раскрыто до КО. Его состав свёрнут. Доступны «До комплексных объектов», «Развернуть всё», «Свернуть всё». На странице отображаются 25, 50 (по умолчанию), 100 или все КО; настройка сохраняется в браузере. Переключение страниц выполняется целыми КО, а их состав загружается полностью. Работы без КО показываются в своих разделах. Выбор всех работ на странице учитывает скрытые страницы дерева; отдельный выбор КО для удаления всегда означает весь его состав.
