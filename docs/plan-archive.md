# Архив планов

В «Планировании на период» нажмите «В архив» напротив плана. Эта же кнопка есть в карточке плана и на странице удаления, в том числе если удаление заблокировано связями. Откроется подтверждение с количеством версий.

Архивируется рабочее пространство целиком, со всеми его версиями. Версии не удаляются: согласования, распределения, дневные СМГ, источники и связи сохраняются. Работы, строительные объекты, исходные индивидуальные месячные планы и фактические данные не удаляются. Отдельные планы-продолжения и планы других рабочих пространств не архивируются автоматически.

Архивный план исключается из активных списков, выпадающих списков выбора версии, автоматического выбора текущего плана и очереди связанных заданий. Его ГПР/СМГ не открываются для редактирования по прямой ссылке. Зафиксированные исторические сводные отчёты не переписываются: их сохранённые снимки и ссылки происхождения остаются историей.

Для восстановления откройте «Архив планов» в списке планирования и нажмите «Восстановить». Версии возвращаются с прежними статусами, согласованиями и распределениями; связанные задания снова доступны по обычным правилам.

Архивирование и восстановление доступны администратору компании. Планировщик может архивировать/восстанавливать только свои назначенные объекты и только планы без согласованной истории (версии DRAFT/REJECTED). Каждое действие требует подтверждения в форме и записывается в аудит.

При обновлении примените миграцию `python manage.py migrate` и перезапустите приложение.
