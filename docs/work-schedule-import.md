# Импорт состава работ из графика

В справочнике «Работы» доступна кнопка «Импорт состава работ из Excel» для администратора и планировщика. Это отдельный импорт справочника: запрет создавать новые работы при импорте ГПР/СМГ сохраняется.

Выберите раздел строительного объекта, профиль нагрузки новых вложенных работ и XLSX. После проверки показывается предпросмотр, затем отдельная кнопка сохраняет данные целиком одной транзакцией. Файл должен содержать согласованные заголовки в A–G и «План» / «Факт» в J. Обрабатываются листы с такими заголовками. Объединённые ячейки читаются по верхней левой ячейке.

Соответствие:

| Excel | Справочник |
| --- | --- |
| Участок производства работ | Комплексный объект в выбранном строительном объекте |
| Группа работ | Комплексная работа |
| Раздел РД | Поле комплексной работы |
| Пункт в РДЦ | Поле комплексной работы |
| Вид работ | Работа в составе комплекса |
| Ед. изм. | Единица вложенной работы |
| Проектное количество | Норматив вложенной работы на комплекс |

Количество комплексного объекта всегда 1 шт. Единица комплексной работы остаётся пустой: её можно задать позже в карточке. Профиль выбирается явно, поскольку он обязателен для вложенных работ и отсутствует в Excel. Новые единицы вложенных работ добавляются в справочник единиц. Вес, цена и плановый объём не назначаются по догадке. Факт, остатки, календарный план, комментарии о стоимости и цветовые отметки не импортируются.

Идентификация: строительный объект → комплексный объект по имени → комплексная работа в выбранном разделе по имени → вложенная работа по имени. Повторный импорт пропускает совпадающие работы. Отличия нормативов, единиц и реквизитов РД не перезаписываются: показывается ошибка. Неоднозначные совпадения отклоняются. Существующие ограничения на изменение структуры работы с планом/фактом действуют и здесь; ошибка откатывает весь импорт.

Предпросмотр подписан и привязан к пользователю, компании, разделу и профилю, действует 15 минут. При подтверждении заново проверяется доступ к разделу и профилю и актуальное содержимое справочника. Импорт журналируется. Лимиты: XLSX до 5 МБ, распакованный архив до 32 МБ, лист до 5000 строк и 100 столбцов, до 2000 уникальных работ. Формулы в импортируемых A–G отклоняются, дневные значения не вычисляются.

Проверка предоставленного файла «График для портала.xlsx»: 2 комплексных объекта (УЗА 26 и ЛЧ), 13 комплексов работ, 35 вложенных работ; 35 строк факта пропущены. Это проверка разбора файла без загрузки в серверную базу.

Проверки реализации: 21 тест импорта, обязательных профилей и выбора расположения работ прошёл; миграции согласованы с моделями. Общий прогон приложения works: 99 тестов, 4 прежних сбоя в batch_prepare, catalogs и list_filters. Все четыре воспроизведены с исходной формой из main и исходной обязательностью единицы; они не исправлялись в рамках импорта.
