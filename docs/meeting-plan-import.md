# План из файла совещания

В редакторе версии откройте **Excel → Импорт файла совещания в эту версию**.
Объект и проект уже определены: выберите период внутри версии и файл.
Будет прочитан только лист с названием текущего объекта и только столбцы дат
выбранного периода. После предварительного просмотра нажмите **Записать в текущую
версию**. Новое рабочее пространство и новая версия не создаются.

Найденные строки работ, людей и техники обновляются за соответствующие месяцы,
недостающие позиции добавляются. Остальные строки и месяцы, включая ГСМ,
сохраняются. Месячный объём работы заменяется суммой выбранных дневных значений
файла, даже если выбран неполный месяц. Подработы сохраняют исходные объёмы,
основная составная работа рассчитывается по нормативам. Импорт разрешён только
в черновик или версию на доработке, в месяцы, доступные для редактирования.
Просмотр привязан также к версии; её доступность проверяется повторно при записи.

Отдельный массовый импорт **Планирование на период → Импорт файла совещания**
по-прежнему создаёт новые планы объектов:

1. Выберите проект, начало и конец периода загрузки и файл `.xlsx`.
2. Выберите правило для переменного дневного количества людей/техники:
   максимум или первый заполненный день в каждом месяце выбранного периода.
3. Нажмите **Предварительный просмотр**, раскройте нужные листы и проверьте строки.
4. Отметьте листы и нажмите **Загрузить выбранные листы**.

Название листа сопоставляется с названием **существующего** строительного объекта
выбранного проекта и компании. Пробелы нормализуются, регистр не влияет на сопоставление. Новые строительные
объекты не создаются. Отсутствующие или неоднозначные совпадения блокируют лист.

Импорт читает только дневные столбцы с реальными датами Excel, попавшими в
заданный период включительно. Даты не переносятся между годами или месяцами.
Месячные и накопительные итоги не используются; строки факта игнорируются.
Листы сводных справок без дневных дат для этой загрузки не подходят.

Объёмы работ суммируются по выбранным дням каждого месяца. Для существующих
составных работ нужны строки всех подработ, включая нули: сохраняются исходные
объёмы подработ, а основной объём вычисляется по минимуму выполнения нормативов
с учётом настройки дробных единиц. Единицы подработ сохраняются с точностью до
шести знаков, основные объёмы — до трёх. Нормативы из произвольных чисел файла
не выводятся.

Недостающие работы создаются простыми, с равномерным профилем. Заголовки блоков
сохраняются как разделы; строки «в том числе» используются как заголовки,
чтобы не загрузить одновременно итог и его расшифровку. Новые единицы добавляются
в справочник. Новые бригады и виды техники создаются с единицами «чел.» и «ед.»;
группы ресурсов сохраняются как группы бригад и категории техники. Госномера
сохраняются, если они выделены в отдельный столбец и укладываются в 50 символов.

Месячное количество ресурсов повторяется каждый календарный день в пределах
периода плана. Если исходное количество меняется по дням, предварительный просмотр
показывает предупреждение и выбранное значение. Исходный дневной график работ
не копируется: система формирует его заново по профилям и производственному
календарю, как при обычном планировании.

Для каждого выбранного объекта создаётся **новое рабочее пространство с базовым
черновиком** на заданный период. Существующие планы и факты сохраняются. После
импорта откройте планы, проверьте данные и сформируйте дневной план перед отправкой
на согласование. Календарь по умолчанию должен быть настроен на каждый год периода.

Пустые значения пропускаются, явные нули загружаются. Итоги ресурсов не
дублируются. Формулы читаются по результату последнего сохранения Excel и не
вычисляются приложением. Ошибки формул в выбранных дневных значениях, повторные
даты, неоднозначные строки и неполный состав подработ блокируют выбранный лист.
Ошибки вне выбранного периода не мешают загрузке.

Предварительный просмотр ничего не записывает в базу. Подтверждение проверяет
сопоставление ещё раз и загружает выбранные листы одной транзакцией: при ошибке
изменения всей операции откатываются. Просмотр действует час и привязан к
пользователю и компании; после успешной загрузки его нельзя использовать повторно.
Импорт доступен администратору и планировщику.

Файл до 8 МБ, до 100 листов. На листе до 2500 строк, 4096 дневных столбцов и
2 миллионов ячеек рабочего диапазона. Пустое форматирование Excel до столбца XFD
не расширяет рабочий диапазон импорта.
